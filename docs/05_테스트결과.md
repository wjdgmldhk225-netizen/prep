- 작성일: 2026-10-12
- 구현 대상: EPIC 1 — 판매 기록과 메뉴 수익성, Story 1.1~1.5만 구현.
- 현재 상태: 구현·자동 검사·개발자 브라우저 검사 통과. **사용자 확인 대기이며 EPIC 완료로 표시하지 않았다.**
- 사용자 테스트 주소: `http://127.0.0.1:5173/`. 로컬 Vite 서버를 켜 두었다.
- 개발자 브라우저 검사: `http://localhost:5173/`에서 수행했다. 주소가 달라 사용자 테스트 저장소와 별개이며, 개발자가 만든 9월 19일 판매만 검사 후 삭제했다. 제공 원본 파일은 변경하지 않았다.
- EPIC 2·3은 미착수. 비용·손익·재료 화면, 백업·복원·배포 기능은 이번 결과에 포함하지 않는다.

TypeScript 검사 통과. Vite 빌드 성공. Zod 패키지의 주석 위치에 대한 Rollup 경고가 있으나 주석 제거 안내이며 빌드 실패·앱 오류는 아니었다.

브라우저 검사 중 날짜 입력 변경이 반영되지 않는 문제가 발견되어 날짜·월 입력 이벤트를 수정하고 다시 확인했다. 저장 전 입력 버리기·원가 기준 변경 확인도 화면 내부 확인 버튼으로 보완했다. 최종 코드에서 위 검사를 통과했다.

속도 단건 관찰: 저장된 자료 재열기 후 실제 화면 준비 시점은 탐색 시작으로부터 **235ms**(앱의 DOM 검사값), 조회 적용과 결과 확인은 **294ms**(브라우저 자동화 왕복 포함)였다. 목표인 재열기 2초·조회 0.5초 안에 들어왔다. 이는 해당 개발 환경의 단건 관찰이며 장기·여러 기기·실제 배포 성능 보장은 아니다. 자동화 도구의 재열기 호출 대기는 2~20초 변동이 있어 실제 앱 준비 시간과 분리했다.

## 5. 현재 범위 마무리와 데모 인계

- 인계일: 2026-10-12. 사용자 요청에 따라 현재 구현 범위를 동결하고 데모 진행으로 전환했다. 추가 EPIC 구현·GitHub 업로드·Vercel 배포는 진행하지 않았다.
- 데모 가능 범위: 기간·메뉴·채널별 판매 조회, 실제 판매 추가·수정·삭제와 저장, 메뉴별 수익성 분석. 자동 검사 28개와 개발자 실제 화면 검사는 통과했다.
- 사용자 검수: U01 통과. U02~U11은 확인 대기로 남겼으며 EPIC 전체 완료로 표시하지 않았다.
- 데모 주소: http://127.0.0.1:5173/#/sales . 현재 로컬 서버와 브라우저를 유지한다. 다른 사람에게 공유할 배포 주소가 아니며 이 컴퓨터에서 실행한다.
- 저장 위치: 현재 브라우저의 이 주소에 저장된다. 데모 동안 동일한 주소와 브라우저를 사용한다.
- 미구현 범위: 비용 관리·매장 전체 손익·재료 잔량 화면, 전체 백업·복원과 비공개 배포. 메뉴의 기여이익은 식재료·포장·결제수수료를 뺀 금액이며 매장 전체 손익과 다르다.

### 데모 진행 순서

1. 판매 기록 관리에서 초기 전체 기간의 6,112건과 저장 상태를 보여준다.
2. 신규 판매 기록 추가에서 2026-09-19·카페라떼·포장·12잔·단가 4,800원·할인 2,000원·개당 식재료 1,123.2원·개당 포장 172.8원·총 수수료 800원을 입력한다. 포장 원가는 기본값 166.4원에서 설명용 값으로 직접 바꾼다. 순매출 55,600원·기여이익 39,248원·70.6%를 확인하고 저장한다. 같은 날짜·메뉴·채널 기록이 이미 있으면 기존 기록을 확인한다.
3. 9월 19일·포장으로 조회하고 메뉴별 수익성 분석에서도 같은 조건을 적용해 판매 입력 결과가 분석에 연결되는 모습을 보여준다.
4. 필요하면 해당 데모 기록을 10잔으로 수정하고 수수료 확인 후 저장한다. 순매출 46,000원·기여이익 32,240원으로 바뀐다. 새로고침 후 같은 조건으로 다시 조회해 저장을 보여준다.

이 순서는 데모 안내이며 미실행 사용자 검수의 통과 근거가 아니다. 다음 개발 작업은 남은 EPIC 1 검수 상태를 확인한 뒤 별도 요청으로 정한다.
