# 프렙 카페

현재 EPIC 1(판매 기록과 메뉴 수익성)만 구현된 로컬 검수 버전입니다. 사용자 검수 완료 전 EPIC을 완료로 표시하지 않습니다.

## 실행

Node.js 24.x를 사용합니다. `npm ci`로 잠금 파일과 같은 의존성을 설치하고 `npm run dev`로 실행합니다. 로컬 주소는 `http://127.0.0.1:5173`입니다.

`npm run build`는 TypeScript 검사 → 자동 검사 → 배포 파일 생성을 순서대로 실행합니다. `npm test`로 자동 검사만 실행할 수 있습니다.

## 현재 범위

제공 가상 자료 최초 준비·기간/메뉴/채널 조회, 판매 추가·수정·삭제·원가와 수수료 정정, 메뉴 수익성, IndexedDB 저장·다시 열기를 구현했습니다. 재료 사용량 영향은 공통 계산 자동 검사로 검증하며 재료 화면은 EPIC 2에 남겨둡니다.

판매·비용을 포함한 제공 원본은 브라우저 기록 보존을 위해 초기 저장합니다. 비용 기능·매장 손익·재료 화면은 아직 구현하지 않았습니다. 백업·복원·GitHub/Vercel 배포는 EPIC 3에 남겨둡니다. 현재는 가상 자료만 검수합니다.

작업 기록은 지정 브라우저와 주소의 IndexedDB에 저장합니다. 외부 서버로 변경한 판매를 보내지 않습니다. 브라우저 자료를 삭제하면 별도 백업 없는 기록은 복구할 수 없습니다. 기록 초기화를 자동으로 수행하지 않습니다.
